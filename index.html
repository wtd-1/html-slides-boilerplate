Pure HTML Slides

One file. No framework. Open it in any browser.

Step-by-step reveals

  • Add class="fragment" to any element.
  • Each "next" shows one more fragment.
  • Screen readers hear each new fragment.
  • A presentation remote sends PageDown and PageUp, so it works too.

Inline SVG with animation

SVG is part of HTML. Its own animation (<animateMotion>) runs live.

The bars use CSS (Cascading Style Sheets) animation and restart on each visit.

GIF and video

A GIF (Graphics Interchange Format) is a plain <img>.

The Pause button freezes GIFs, SVG, CSS, and video.
