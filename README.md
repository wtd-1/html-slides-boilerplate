# html-slides-boilerplate
HTML is one of the most convenient ways to flexibly render a presentation such that mathematics and animations are supported. Further, it is also free. We present a HTML template for presentations that uses strictly Mathjax and nothing more. 

An upshot of this template in particular is that it is as disability-friendly as it can be, barring for the author's own preference for serif fonts. This can easily be changed, however, on account of the default font as prescribed in the file.
