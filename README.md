# html-slides-boilerplate
HTML is one of the most convenient ways to flexibly render a presentation such that mathematics and animations are supported. Further, it is also free. We present a HTML template for presentations that uses strictly Mathjax and nothing more. Everything is provided in the file alone; the only requirement is that the file it actually downloaded and altered to the user's liking. No other work is required above that. 

An upshot of this template in particular is that it is as disability-friendly as it can be, barring for the author's own preference for serif fonts. This can easily be changed, however, on account of the default font as prescribed in the file.
